## Selected Projects

### 🌱 SkillFarm

**AI-powered personalized learning platform**

A production-oriented platform that creates personalized learning roadmaps and provides specialized AI mentors based on a user's learning profile.

**Highlights**

* Personalized learning profile and roadmap generation
* Specialized AI mentor architecture
* Multi-provider LLM integration
* Streaming AI conversations
* Long-term memory
* Resume-based skill extraction
* Redis-backed rate limiting and caching
* PostgreSQL-backed application data

**Status:** Live · Source code private

🔗 **[Visit SkillFarm](https://skillfarm.in/)**

---

### 💬 ChatMate

**Multi-LLM AI chat platform**

A ChatGPT-style application supporting multiple LLM providers with real-time streaming, conversation branching, tool calling, and persistent chat history.

**Stack:** Next.js · React · TypeScript · Vercel AI SDK · OpenAI · Gemini

🔗 **[Portfolio](https://www.ravindrayadav.online/)**

---

### 📚 ChaiBookLM

**RAG-powered research assistant**

A full-stack research assistant inspired by modern document-grounded AI applications. Users can upload sources, build a knowledge base, and interact with their information conversationally.

**Stack:** Next.js · Prisma · Neon · Qdrant · Cloudflare R2

🔗 **[Portfolio](https://www.ravindrayadav.online/)**

---

### 🧑‍💻 MentorOS

**AI mentoring platform**

An AI mentoring system with specialized mentor personas, external tool integration, multi-provider LLM routing, and controlled access through rate limiting.

**Stack:** Next.js · PostgreSQL · Drizzle ORM · Redis · OpenAI · Gemini

🔗 **[Portfolio](https://www.ravindrayadav.online/)**

### ⚔️ AI Arena

**Multi-LLM comparison & evaluation platform**
