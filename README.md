## 👋 About Me

I'm a **BCA student and software developer** interested in building practical software and understanding how things work under the hood.

I enjoy exploring the engineering behind applications, from data structures and backend architecture to AI systems that retrieve context, use tools, and maintain memory. I learn best by building, experimenting, and solving problems rather than just following tutorials.

- 🚀 **Product Builder:** Created and shipped [SkillFarm](https://skillfarm.in), an AI-powered learning workspace that helps developers move from learning concepts to building real projects.
- 🏆 **Hackathon Winner:** Won 1st place and ₹20,000 at Martinovation 2026 with [P2Shield](https://p2shield.vercel.app), an LLM privacy firewall, among 52 teams.
- 🧠 **Technical Interests:** Full-stack engineering, AI agent workflows, RAG, conversational memory, and real-time systems.
- 🎯 **Currently Focused On:** Starting a consistent DSA practice routine, strengthening problem-solving fundamentals, and building better AI-powered applications.

### 🛡️ [P2Shield](https://p2shield.vercel.app)

**🏆 1st Place · Martinovation 2026**

Built in 24 hours and awarded ₹20,000 among 52 competing teams.

An LLM privacy firewall that intercepts prompts before they reach AI providers and protects sensitive information.

- Detects API credentials and personally identifiable information
- Uses regex matching and named entity recognition
- Redacts sensitive data using a token vault
- Supports workflows involving OpenAI and Gemini
